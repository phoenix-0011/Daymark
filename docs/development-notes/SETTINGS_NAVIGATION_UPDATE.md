# Settings and Navigation Update

This update restructures Daymark's primary controls:

- The persistent top-right control is now a Settings gear.
- Language and appearance controls are located in Settings.
- Category creation and deletion are managed in Settings.
- The task-category chips remain available for filtering, but category creation is no longer shown beside them.
- The Add Task action is a circular floating button positioned above the Mine item in the mobile bottom navigation.
- On wider desktop layouts, the same Add Task button stays at the lower-right of the content area.

Settings opens as a managed page below Daymark's persistent header on Android and as a compact dialog on desktop.

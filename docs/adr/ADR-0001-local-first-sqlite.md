# ADR-0001: معماری Local-first با SQLite

- وضعیت: Accepted
- تاریخ: 2026-07-30

## زمینه

Daymark یک Task Planner تک‌کاربره است و در دامنه دانشگاهی فعلی به حساب کاربری، همگام‌سازی یا Backend نیاز ندارد.

## تصمیم

SQLite به‌عنوان منبع اصلی داده انتخاب شد و وظایف، زیرکارها، دسته‌بندی‌ها و History در فضای محلی برنامه ذخیره می‌شوند.

## دلایل

- عملکرد آفلاین
- سادگی استقرار
- Transaction و Foreign Key
- Queryهای مناسب تاریخ، وضعیت و Category
- کاهش سطح حمله و هزینه Backend

## پیامدها

- Cloud Sync وجود ندارد.
- Backup و انتقال داده بین دستگاه‌ها خارج از دامنه است.
- Migration دیتابیس باید با Regression Test محافظت شود.
- امنیت فیزیکی و Backup سیستم‌عامل بر محرمانگی داده اثر دارد.

# نسخه ارائه Android-only

این مجموعه برای معرفی Daymark به‌عنوان یک برنامه Android بازبینی شده است.

- تمام اسناد و نمودارها فقط برای نسخه Android بازنویسی شده‌اند.
- فایل‌های PlantUML برای معماری، وابستگی بسته‌ها و استقرار به Android محدود شده‌اند.
- SVGهای قبلی عمداً حذف شده‌اند؛ برای جلوگیری از نمایش خروجی قدیمی، آن‌ها را دوباره تولید کنید.

```bash
chmod +x render_diagrams.sh
./render_diagrams.sh
```
